MS MOBILA — PROJETO ANDROID INICIAL

IMPORTANTE:
Este ZIP contém um protótipo de editor visual de controles. Ele permite adicionar,
arrastar e salvar marcadores de controles no próprio aparelho.

AINDA NÃO É um mapeador funcional dentro do Free Fire:
não captura teclado/mouse, não injeta toques no jogo, não implementa analógico
360 graus real e não cria painel flutuante sobre outros aplicativos. Essas partes
exigem implementação Android específica, permissões/serviços compatíveis e testes
em aparelho real. Não considere este protótipo pronto para competir ou vender.

COMO ABRIR:
1. Instale Android Studio no Windows.
2. Extraia o ZIP para uma pasta.
3. No Android Studio, escolha Open e selecione a pasta MS_MOBILA.
4. Aguarde a sincronização do Gradle.
5. Conecte o celular com Depuração USB habilitada e use Run para testar.

Requisitos do projeto: Android Gradle Plugin 8.7.3, Kotlin 2.0.21,
compileSdk 35, minSdk 26.
